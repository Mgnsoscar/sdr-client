Tune step labels

A tune step is an instant on the timeline — a pin plus a short caption of the parameter it changes. Today that caption leads with the task name in a filled badge and then dumps a raw power=−10.50 dBm/MHz string. The name is redundant (the pin's colour already says which task), and the raw key=value reads unstyled. Below: the current look, then three restyled captions that drop the name and give the reading a real label · value · unit treatment.

The colour already carries the task — teal is the GPS C/A signal, violet the chirp — and the row header on the left repeats the task name in full. So the badge on every pin is saying what the colour just said.
Reuses the editor's real styling — IBM Plex Sans / Mono, the per-task hue, and the power-unit family colours (slate = absolute dBm, teal = a spectral density, from _unit_family).
