What changed vs today
  • The quantity you're setting is one clear primary control — big editable value, unit, a range rail with labelled MIN / MAX, and the fold-frequency note.
  • Every other quantity gets its own read-only display field (name, live value, unit) instead of a run of = … · name lines — so it's obvious what each number is.
  • Control in this on any field promotes it to the primary; the commanded output never changes, only which quantity you type in (today's control in dropdown).
  • Unit chips are colour-coded by family — slate for absolute dBm, teal for a spectral density — matching the Calibration tab.
