Two-sided tune pins

A tune point can be a step-anchor target (a connector exits it) AND a dependent (a connector enters it) at once — a chain like A → this → C. Then a line runs off both sides at the pin's row, so neither left nor right is free for the readout chip: the earlier "flip to the empty side" trick has no empty side. Below: the collision, then ways to keep the line off the text. (One hue shown; it holds for any task colour. The blue lines are connectors; the +0:30 tag is a connector's own offset chip, which must stay clear too.)
